# Light Mode Color Fix - Aurora Breeze Theme

## Problem
Original light mode had clashing colors:
- Teal base (#088395) mixed with violet, purple, pink, coral
- No unified color harmony
- Cool teal clashed with warm coral and vibrant violet/purple

## Solution: "Aurora Breeze" Theme
**Color Harmony**: Cool Analogous + Tetradic Scheme

### Primary Colors (Cool Harmony)
- **Sky Blue 500**: #0ea5e9 - Primary brand
- **Cyan 500**: #06b6d4 - Secondary brand  
- **Teal 500**: #14b8a6 - Accent brand

### Accent Colors
- **Indigo 400**: #818cf8 - Periwinkle
- **Violet 400**: #a78bfa - Lavender
- **Indigo 500**: #6366f1 - Blue-violet
- **Sky 400**: #38bdf8 - Sky
- **Emerald 400**: #34d399 - Mint
- **Orange 400**: #fb923c - Coral (minimal use)

### Backgrounds (Clean & Airy)
- **Pure white**: #ffffff
- **Sky 50**: #f0f9ff - Very light blue tint
- **Glass navbar**: rgba(255, 255, 255, 0.9)
- **Sky 100**: #e0f2fe - Cards
- **Sky 200**: #bae6fd - Borders

### Text Colors
- **Slate 900**: #0f172a - Primary
- **Slate 700**: #334155 - Secondary
- **Slate 500**: #64748b - Muted
- **Sky 50**: #f0f9ff - On dark backgrounds

### New Gradients
- **Aurora**: Sky → Cyan → Periwinkle → Lavender → Teal
- **Breeze**: Sky → Cyan → Mint
- **Ocean**: Sky → Dark Sky → Cyan
- **Coastal**: Periwinkle → Lavender → Purple
- **Forest**: Mint → Teal → Dark Teal

### Status Colors (Softer)
- **Operational**: #34d399 (Mint green)
- **Degraded**: #fbbf24 (Warm amber)
- **Down**: #fb7185 (Soft rose)

## Key Changes
1. Replaced clashing teal with harmonious sky blue base
2. Unified cool color spectrum (blue → cyan → indigo → lavender)
3. Added mint as fresh accent instead of harsh emerald
4. Softened status colors for light mode
5. Updated all gradients to use new harmonious palette
6. Changed button/badge shadows to use sky blue instead of violet
